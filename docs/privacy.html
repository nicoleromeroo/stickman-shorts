Privacy Policy — Stickman Shorts Uploader

Last updated: 15 November 2026

What the app does

Stickman Shorts Uploader is a private tool operated by the owner of the YouTube channel @typicalstickmanvids. It uploads videos created for that channel to that same channel using the YouTube Data API. It is used only by the channel owner and is not offered to the public.

Google / YouTube data the app uses

  • The app requests only the youtube.upload permission, which allows it to upload videos to the authorised channel.
  • It does not read, collect or store any other Google account data, YouTube viewing data, comments, subscribers or personal information.
  • The only credential stored is the OAuth refresh token for the owner's own channel. It is kept as an encrypted GitHub Actions secret and is never shared with anyone.

Data about viewers

The app does not collect, store or process any data about viewers or other people.

Sharing

No data is sold, shared or transferred to third parties. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/nicoleromeroo/stickman-shorts/issues.
